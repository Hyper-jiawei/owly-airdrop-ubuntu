# Owly AirDrop for Ubuntu 使用说明

适用于 owly-airdrop-ubuntu 0.1.0（owly 0.4.2 + Ubuntu 桌面组件）。

## 1. 安装与首次启用

```bash
sudo apt install ./owly-airdrop-ubuntu_0.1.0_amd64.deb
gnome-extensions enable owly-airdrop@hyper-jiawei.github.com
```

注销重登（或 `Alt+F2` → `r` → 回车）后，右上角快速设置面板底部出现「AirDrop 接收」开关。

验证：

```bash
owly --version          # owly 0.4.2
owly doctor             # 网卡检测，显示 ready 即可
systemctl is-active owlyd
```

## 2. 日常使用：快速设置开关

- **打开**：自动启动 radio + 接收端，**默认自动接受**，保存到 `~/Downloads`（可在 GUI 中修改）；
- **关闭**：自动归还网卡、恢复 Wi-Fi；
- 副标题实时状态：

| 显示 | 含义 |
| --- | --- |
| `已停止` | 未运行 |
| `启动中…` | 正在拉起 radio / 接收端 |
| `已就绪 → ~/下载` | 真正可接收，iPhone 可搜到本机 |
| `正在停止…` | 正在归还网卡 |
| `由图形窗口管理` | 接收端由 Owly AirDrop 窗口管理 |
| `启动失败` | 启动未成功，查日志 |

- 开关右侧 `>` 菜单：「打开 Owly AirDrop 设置…」「发送文件…」。

> Intel 网卡（iwlwifi）为 exclusive 模式：接收期间 Wi-Fi 断开属正常现象，关闭开关即恢复。

## 3. 图形界面（Owly AirDrop）

应用菜单搜索「Owly AirDrop」，或命令行 `owly-gui`。

- **接收页**：改保存目录、勾选弹窗确认（14 秒不点自动拒绝）；
- **发送页**：选文件 → 搜索设备（20 秒）→ 点设备投送（20 秒超时）；
- 开关运行时打开 GUI 会进入**仅设置模式**：不重复启动接收端，改目录后自动重启开关的接收端；
- 关闭窗口自动清理自己启动的进程；单实例，重复打开会提示已在运行。

参数：`owly-gui --dir ~/下载`、`owly-gui --send`、`owly-gui --no-radio`。

## 4. iPhone 端

1. 解锁 iPhone，控制中心长按网络卡片，AirDrop 设为 **「所有人，10 分钟」**；
2. 分享照片/文件，选择本电脑名称（默认为主机名）；
3. 等开关显示「已就绪」再发送；接收期间不要锁屏。

## 5. 命令行（与 GUI 等效）

```bash
owly-ctl start                          # 开关同款：启动 radio+接收（自动接受）
owly-ctl stop                           # 停止并恢复 Wi-Fi
owly-ctl status                         # state: ready|starting|external|stopped + dir

owly radio up                           # 手动 radio（保持前台，Ctrl-C 结束）
owly receive --dir ~/Downloads --accept # 手动接收
owly browse --seconds 20                # 搜索接收端
owly send --to "iPhone 名称" --seconds 20 photo.jpg
owly doctor                             # 网卡诊断
journalctl -u owlyd -f                  # 守护进程日志
tail -f ~/.local/state/owly-gui.log     # 组件日志
```

## 6. 常见问题

**开关显示已就绪，但 iPhone 搜不到电脑**
- 确认 AirDrop 是「所有人，10 分钟」（10 分钟后会自动失效，需重设）；
- 重启一次 iPhone（清 AirDrop 缓存，官方已知问题）；
- 关闭再打开分享面板重新发现；
- 防火墙若启用，放行 `awdl0` 上 `fe80::/10` 的 TCP 8771：
  `sudo ufw allow in on awdl0 from fe80::/10 to any port 8771 proto tcp`

**分享面板里有多个同名电脑**
- 反复重启接收端产生的过期 mDNS 缓存，会自行过期；重启 iPhone 可立即清除；
- 日常用开关或 GUI（一次一个接收端）即可避免。

**iPhone 点了电脑一直「等待中」**
- 多半点到旧缓存条目或接收端未就绪：等开关显示「已就绪」、重启 iPhone 后重试；
- 查 `~/.local/state/owly-gui.log` 是否出现 `seen by ...`（AWDL 层已连接）与 `wants to send`（收到请求）。

**端口被占（Address already in use）**
- 同时开了多个接收端。`owly-ctl stop` 并关闭多余 GUI 窗口后重试。

**卸载**
```bash
sudo apt remove owly-airdrop-ubuntu     # 或 purge 连配置一起清
```

## 7. 硬件支持

| 网卡 | 驱动 | 模式 |
| --- | --- | --- |
| Intel AX210/AX200/AX201/AX211 | iwlwifi | exclusive（接收时 Wi-Fi 断开） |
| MediaTek MT7925 | mt7925e | shared |
| Realtek RTL8852CE | rtw89_8852ce | shared / exclusive |

完整列表与未测试网卡的 `allow_untested` 配置见 `owly/README.md` 与 `owly/hardware/`。
